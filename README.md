>
> 为什么说 ICT 是交易界的中医（TCM）？因为**复盘画图时百发百中、头头是道；一旦去掉“老师盘感”、写成可证伪的规则上机实测，立马开始稳定兑现经典的 `-91% promised`**。

## 太长不看（TL;DR）

我们拿 **BTCUSDT 现货** 从 2023 年 1 月到 2026 年 10 月共 **46 个月、2,015,920 根 1 分钟 K 线**，严格按手册默认参数把核心模型写成了无情的代码机器。跑完 395 笔真实成交后，成绩单如下：

* **净亏损**：**-106.8R**（单笔净期望 **-0.270R**），每亏 1 块钱只能赚回 6 毛 3（盈亏比 PF = 0.63）
* **最大回撤**：**113.4R**——如果你每笔拿本金的 1% 去赌，恭喜你，账户直接干到归零级别，原汁原味复刻传说中的 `-91% promised`
* **毛收益约等于零**：就算交易所免除你所有手续费和滑点，平均每笔也只赚 **+0.061R**（95% 置信区间横跨 0，统计学上等于抛硬币）
* **不如反向做**：在完全相同的入场点**闭眼跟 ICT 反着干**，不含成本的毛期望是 **+0.094R**，甚至比顺着 ICT 做还高一点点

## 1. 把 ICT 黑话翻译成人话：我们到底测了什么？

为了防止有人说“你测的不是正宗 ICT”，这套回测尽量还原了手册里能写进代码的全部核心动作（基于 2026-11-27 回测版本）：

* **考场与时间**：Binance Vision 的 BTCUSDT 现货 1 分钟数据（2023-01 至 2026-10），按纽约时间跑加密适配时段——09:30 到 11:30 找机会，11:30 还没成交就撤单，最晚 16:00 强制清仓睡觉
* **大方向（偏向）**：价格在前一天波动区间 50% 上方只做空，下方只做多
* **连招触发**：扫荡流动性池（刺破后 3 根 5 分钟 K 线内收回）→ 暴力位移（实体 ≥ 1 倍 ATR14，或实体占整根 K 线 ≥ 60%）+ 结构破坏（MSS）+ 留下失衡缺口（FVG）
* **进出场**：在 FVG 近端挂限价单进场，止损放在扫荡极值外 0.1 倍 ATR 处；主版本止盈看固定 **2R**（赚两倍止损的钱），另测了看到对侧流动性池的版本
* **撮合与成本**：1 分钟逐根撮合，同一分钟里止损和止盈同时碰到时，按先打止损算；默认按往返 **12bps**（买+卖手续费加滑点共 0.12%）计成本，同时测了 6bps、2bps 和 0 成本

(注：1R 就是你这笔单子“开仓价到止损价”愿意亏掉的固定金额，所有盈亏都用 R 记账。)

## 2. 战绩惨案：说好的 2R 狙击，全靠收盘捡钢镚

46 个月里，系统一共识别出 **670 次** 符合教义的“完美形态”，其中 **395 笔** 成交（成交率 59%），中位持仓 115 分钟。

| 核心指标 | 实测结果 | 人话翻译 |
| --- | --- | --- |
| 净胜率 / 毛胜率 | 37.5% / 42.3% | 十次里赢不到四次 |
| 2R 止盈命中率 | 23.0% | 吹上天的 2R 目标，不到四分之一能打到 |
| 止损率 | 50.4% | 一半以上的单子直接原地阵亡 |
| 到点强平率（16:00） | 26.6% | 晃悠一下午没出结果，收盘被迫离场 |
| **毛期望（零成本）** | **+0.061R** | 95% 置信区间 `[-0.067, +0.183]`，和没优势没区别 |
| **净期望（@12bps）** | **-0.270R** | 95% 置信区间 `[-0.401, -0.145]`，稳稳地亏钱 |
| 最大回撤 | 113.4R | 按 1% 仓位算已爆仓，中途早触发手册的 10% 停手线 |

把这 395 笔单子拆开看，画面更喜感：

| 结局 | 笔数 | 平均每笔 R | 合计 R |
| --- | --- | --- | --- |
| 惨遭止损 | 199 | -1.000 | -199.0R |
| 精准打到 2R | 91 | +2.000 | +182.0R |
| 16:00 到点平仓 | 105 | +0.391 | +41.1R |
| **零成本毛合计** | **395** | **+0.061** | **+24.1R** |
| 交给市场的手续费与滑点 | — | -0.331 | -130.8R |
| **最终净合计** | **395** | **-0.270** | **-106.8R** |

看见华点了吗？**“打到 2R”赚的 +182R 和“止损”亏的 -199R 对冲完，还倒欠市场 17R**。这套系统在免手续费的情况下之所以勉强翻红（+24.1R），全靠那 105 笔“磨蹭到下午四点没打止损”捡回来的 +41.1R 零碎利润。也就是说，**ICT 宣称的 2R 暴击根本没兑现**。

算笔小学数学账就知道这不是“差一点运气”：考虑到时间退出平均能捡回 +0.39R，零成本下 2R 命中率只要约 21% 就能保本；但加上 12bps 交易成本后，保本线直接飙回 **32%** 左右。实测只有 **23.0%**，离回本线还差着足足 9 个百分点。

## 3. 灵魂拷问：这套连招比猴子扔飞镖强吗？

为了检验“扫荡 → 位移 → MSS → FVG”到底有没有预测方向的魔力，我们在**零成本**下把 ICT 模型和几个摆烂策略放在同一张桌子上比试：

| 做法 | 零成本毛期望 | 点评 |
| --- | --- | --- |
| **本模型（正宗 ICT 机械连招）** | **+0.061R** | 学了几百小时黑话的成果 |
| 同时段随机进场（顺偏向，1ATR 止损 / 2R 止盈） | -0.011R | 随便找个点位跟大方向 |
| 同时段随机进场 + 随机多空 | +0.031R | 闭眼扔硬币 |
| **在 ICT 实际入场点直接反向做** | **+0.094R** | **最强策略竟然是“反买别墅靠海”** |

四位选手的成绩全挤在 0 附近，统计学上根本分不出高下。翻译一下：**折腾半天的流动性扫荡和 FVG，并没有给你提供任何有效的方向信息**。

## 4. 交易所的活雷锋：超窄止损 + 手续费粉碎机

很多人会问：“是不是你手续费设太高了？” 我们把往返成本一路砍到骨折：

| 往返成本（费+滑点） | 单笔净期望 | 95% 置信区间 | 盈亏比 PF |
| --- | --- | --- | --- |
| 12bps（保守现货） | -0.270R | -0.401 … -0.145 | 0.63 |
| 6bps（大户/低滑点） | -0.105R | -0.233 … +0.018 | 0.83 |
| 2bps（做市商级费率） | +0.006R | -0.121 … +0.128 | 1.01 |
| 0bps（慈善交易所） | +0.061R | -0.067 … +0.183 | 1.12 |

在 12bps 成本下，你平均每笔单子光是摩擦成本就要交掉 **0.331R**——是零成本毛收益（+0.061R）的 **5.4 倍**。哪怕把成本压到近乎免费的 2bps，也只是勉强打平。

更要命的是 ICT 招牌的“极致狙击窄止损”：这 395 笔单子的中位止损宽度只有价格的 **0.531%**（平均 0.633%）。其中有 **54 笔**止损窄到 **< 0.2%**：

| 止损宽度 | 笔数 | 平均每笔成本 | 平均每笔净收益 | 现状 |
| --- | --- | --- | --- | --- |
| `< 0.2%` | 54 | 0.956R | -0.935R | 还没上赌桌，茶水费先交一整注 |
| `≥ 0.2%` | 341 | 0.232R | -0.165R | 从“光速暴毙”变成“慢性失血” |

这 54 笔超窄止损单合计亏掉约 **50R**，一口吞掉了总净亏损的 **47%**。就算把它们全删掉，剩下的 341 笔毛期望也只有 +0.067R，扣完 0.232R 的成本照样每笔净亏 -0.165R，根本翻不了身。

## 6. 为什么叫 “ICT is a TCM”？（提前帮信徒叠甲）

做量化讲究实事求是，这份回测也有明确的边界。同时，我们也可以提前预判评论区一定会出现的“老中医辨证施治”式反驳：

* **“BTC 不是 NQ/ES 期货！”** —— 这点完全公道。手册首选的是美股指期货 ES/NQ，本回测按手册 §7.5 的加密适配重建了时段（9:30 开盘锚而非原版 8:30），且期货的时段效应更强、费率更低，换品种结果可能会不同。
* **“你没加 HTF 大周期叙事、没看 SMT 背离、没躲新闻日、没主观挑池子！”** —— **这正是 TCM 的精髓所在**。本仓库只把能写成明确规则的部分编了码。至于那些没法量化的“盘感、叙事、选池裁量”，它们当然可能真的是隐秘的赚钱魔法，但也极有可能只是复盘时怎么圆都圆得上的**事后诸葛亮**。
* **关于样本与过拟合**：全程用手册默认值，没做暴力调参过拟合；395 笔样本足以证明这里面没有“暴利圣杯”，但不足以排除存在极微弱优势的可能——只是就算取 95% 置信区间的最乐观上限（+0.183R），也依然填不满 12bps（0.331R）的成本大坑。
* **执行假设**：限价单触及即成交（没算排队，实盘成交率可能更惨）；同一分钟先算止损偏保守；用的现货数据没算永续合约资金费率；过去四年的行情也不代表未来。

一句话总结这份实验证明了什么：**它无法证伪活在信徒大脑里的“裁量版 ICT”，但它清清楚楚地证明了——把 ICT 写成明确规则、按默认参数在 2023–2026 的 BTCUSDT 上实打实地跑，不仅不赚钱，还是给交易所送钱的永动机**。

## 7. 复现指南（不服自己跑一遍）

代码和数据全都在仓库里，拒绝事后画图，欢迎拉下来亲自验证：

```bash
cd backtest
python download.py
python backtest.py --target fixed --baseline
python backtest.py --target fixed --disp 0.8 --out trades_fixed_disp08.csv
python analyze.py
python managed.py
```

* `download.py`：首次运行会自动拉取 46 个月的 1 分钟 K 线数据，本地缓存约 90MB（已在 `.gitignore` 中排除）
* `backtest.py`：跑主策略及基线对照，默认输出成交明细 `trades_fixed.csv`（395 笔）；加上 `--out` 参数保存 0.8 ATR 敏感性测试结果，另有对侧池目标明细 `trades_pool.csv`（340 笔）
* `analyze.py`：输出不同费率情景、随机入场与反向交易基线对比
* `managed.py`：模拟 T1 分批止盈与移保本等仓位管理变体
